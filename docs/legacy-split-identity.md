# 旧分割盤面のID移行

旧Grid生成器の出力と一致する分割済み盤面を、読込時に復元可能な形式へ移行する。
頂点間、頂点と辺途中、辺途中同士の分割と、旧結合後の分割を扱う。
現在のセル・頂点・辺のID、向き、位置、境界、数字・線・頂点注記は変更しない。

## 互換処理の境界

`legacySplits` はGrid設定と表示プリセットから旧出力を生成し、全要素のID・座標・
境界・接続・元座標・表示範囲を照合する。似た形状だけでは移行しない。
一致する既知の形式の中だけで、元グラフと保存済みの頂点・辺を対応付ける。
セル名の末尾を解析したり、任意IDから座標を推定したりしない。
子セルのIDも旧生成器の結果から取得し、アプリ側で名前を組み立て直さない。

保存済みのIDはすべて維持する。元の盤面から消えていて復元に必要な頂点・辺だけに
新しいIDを発行し、旧連番を再利用しない。結合元も必要な場合は既知の旧結合アダプターを通す。
スナップショットのない旧形式も、Gridから読み込む互換境界で同じ移行を行う。

## 辺途中の端点と復元

ネイティブ形式1.6は、分割の前後で使う境界の頂点・辺、分割辺の元の向き、
旧形式で子セルへ引き継がれた元セル集合を明示する。
辺途中の頂点と細分化された辺は元グラフ内に復元用データとして保持し、
対応する分割が有効な場合だけ盤面へ含める。
境界は元の角をすべて含み、元の辺上へ順番に点を追加したものでなければならない。
外部の頂点への付け替え、元の角の削除、対応しない辺の混入は拒否する。

「セルを復元」は選択した分割とその依存操作だけを解除する。
他の独立した分割・数字・境界注記を保持し、消えた子セル・分割辺・辺途中の点の注記は除去する。
不要な復元用の点や辺を、盤面上の孤立した要素として残さない。
Undoでは元の分割と注記をまとめて戻す。復元したセルは再度分割できる。

既存の表示プリセットの座標と辺の中点も保持する。
非線形変形後の辺の中点を、両端の座標の平均で再計算して移動させない。
正方・六角格子の対応済み行列変更、除外・再表示、サイズ変更、保存・再読込でも同じ参照を使う。

## 余白セルの役割

旧生成器が分割時に落とした盤外属性は、元セルと出力を分けて保存する。
子セルの役割が元セルと異なる検証済みの旧分割では、境界情報の `outboard` に
保存時の子セルの属性を明示する。二つの子の役割が食い違う場合や、境界が元のセルに
対応しない場合は移行しない。IDの表記から余白かどうかを決めない。

読込時に存在する未編集セルの役割は、保存済みグラフを維持する。
分割前の余白セルは元のID・盤外属性を保持し、分割解除で戻す。
解除後に利用者が新しく分割する場合は、現在の元セルの役割を子に引き継ぎ、
旧分割だけの属性指定を再利用しない。
通常の旧分割と除外を伴う移行の両方で、解除・Undo/Redo・保存再読込を扱う。
明示した出力属性の型や操作再生結果と保存グラフが一致しないファイルは、現盤面を変更せず拒否する。

## 読込経路と未対応範囲

File Open、ストアのimport、共有／自動保存からの読込では、グラフと正規化した
構造設定を同時に適用する。ブラウザの基本Grid設定は分割等を保存しないため、
盤面スナップショットが持つ設定を優先する。構造設定とグラフが矛盾する設定データは
現在の盤面を上書きせず無視する。ネイティブ文書の不整合は読込失敗として返す。

除外済みの旧盤面、彫刻との混在、同一セルへの重複した分割設定、既知の出力と異なる
独自形状・元座標はこの移行の対象外。元のグラフと注記を保持し、由来を推測しない。
旧生成器が作った接続・境界を読み込み時に自動補正する変更でもない。

分割端点を切り落として新しい交点を作る縮小、他格子・独自形状の行列変更、彫刻の
同一性保持等は継続課題である。この移行だけでPR #126をマージ可能とはしない。
