# 参照モード切替の仕様

基準: `bb9ce18`。実装前に固定した仕様に、移行処理と検証を追加する。
[ID契約](board-id-contract.md)と[線入力仕様](line-input-identity.md)に従う。

- ジャンルのツール一覧・設定、線・Freehandの入力動作は維持する。
- Gridの既知の座標参照と、保持したTopologyの不透明IDを、種類ごとの対応表で変換する。
  設定から作った比較用の格子と、実際の行列情報・元座標・境界・接続を照合する。
  比較用の格子で実盤面を置換したり、実盤面を再採番したりしない。
- 問題／解答・試行の注記、線、記号、ケージ、特殊線、部屋、解答範囲、
  多色塗り、除外設定を同時に変換する。レコードID・グループID・Freehand座標は保つ。
  頂点塗りは両モードで同じ実頂点を参照するため変換しない。
- 記号は配置先の種類を保持する。型なしの旧記号は一意に解決できる場合だけ受け入れる。
  同じ文字列の別種類を描画・置換・消去で混同しない。
- モード・参照データ・試行・選択を一体の履歴にする。切替前の保留入力を確定しない。
- 対応不能な形状、欠損・曖昧な参照、解釈不明な拡張データは切替を拒否し、
  元の状態と履歴を保持して理由を返す。結合・分割・彫刻等を通常格子へ潰さない。
- 変形表示からGridへ戻る場合は同じグラフの元座標を使い、Topologyへ戻すと表示設定を適用する。
  保存はその時点のモードと実グラフを保持する。

## 公開APIと対応範囲

`store.getState().setUseTopology(boolean)` は成功時に `{ ok: true }`、
拒否時に `{ ok: false, reason: string }` を返す。同一モードの再指定は何も変更しない。
呼出元は拒否を表示し、成功した前提で後続の編集を行わない。

正方格子と、セル参照を持つ六角格子では、余白編集・除外後の保持盤面も変換できる。
他の格子でも比較用の格子と元座標・接続の対応を検証するが、Grid側に対応する点や
同じ座標系がない場合は拒否する。六角格子の頂点／辺のGrid参照は未対応で、
Topologyの頂点／辺を指す記号・線がある場合はGridへ切り替えられない。
頂点塗りは常にTopologyを参照するため、その制限には当たらない。
未検証の格子を対応済みとは扱わない。

角／辺数字があるセルは、Gridと同じ境界順・配置を確認できることも必要になる。
行列番号や頂点位置だけが一致する独自グラフを、通常格子と同一視しない。
行列のヒントは行列情報として保持し、セルIDへの変換は行わない。
記号には任意の `pointType: 'cell' | 'vertex' | 'edge'` を追加する。

同じセッション内ではTopology表示のプリセットを覚えて切替時に再適用する。
ネイティブ保存が保持する表示設定は保存時に適用中の設定であり、
Gridで保存・再読込した後に以前の変形プリセットを再開する保証は含まない。
他ジャンルの既存ID解析・公開互換APIの整理は引き続き別の移行対象とする。

## 検証

実ストアで任意ID・異種の同名ID・余白と除外・試行・履歴・保存の往復を確認する。
対応不能な切替では盤面・注記・履歴が変更されないことを確認する。
開発ハーネスに公開APIを呼ぶモード切替ボタンを置き、通常のFile Open／Saveと
描画操作をPlaywright + Chromiumで検証する。これはハーネス経由のAPI QAであり、
通常の製品画面にモード切替UIが存在するという主張にはしない。
同じ操作のBefore／After画像・動画を残す。
