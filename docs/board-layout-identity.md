# セルサイズ・外側余白の変更とID

[ID契約](board-id-contract.md)のうち、セルサイズと外側余白だけを変更する操作は、
現在の盤面を再生成せず座標だけを変換する。セル・頂点・辺のMapキー、ID、境界、
隣接を維持する。行列数から復元できない台形等のネイティブ盤面にも適用する。

座標の変換は、元の外側余白を引き、セルサイズの比率を掛け、新しい余白を足す。
セル中心・頂点位置・辺の中点・描画範囲を同じ変換で更新する。
除外前の保持盤面にも適用し、再表示したセルだけが古い大きさになることを防ぐ。
数字・塗り・線の参照先は変更しない。固定座標を持つ自由線や画像等を一括変形する機能ではない。

`setGrid` と `resizeGrid` の両経路で使用し、設定と盤面を一体でUndo/Redoする。
`setGrid` に変更のない行列数・種類等が一緒に渡っても、それだけを理由に再生成しない。
盤面形状パネルのサイズプレビューにも同じ変換を使用する。
Apply直後にもう一度再生成する遅延処理は除去する。
プレビューの盤面と、確定後のパズル要素の位置・保存結果をそれぞれ検証する。

## プリセットとの区別

適用済みプリセットを実行時の `topology.appliedPreset` に記録する。
これはIDの意味付けではなく、表示中の盤面がどの設定を適用済みかを示す情報。
ネイティブ保存や盤面設定の保存では、表示中の盤面の適用済み設定を使用する。
スナップショット読込時は `topologySettings` からこの実行時情報を復元する。
まだ適用していないUI選択を、保存した盤面へ適用済みと記録しない。

プリセットが変更されている場合は、既存のプリセット適用経路を使用する。
その場合まで「以前の形状を単に拡縮する」動作にはしない。
ただし、プリセット変更自体のID維持はこの変更の完了範囲ではない。

## 残課題

行列数・余白セル数の増減、結合・分割、プリセットの変更等には、再生成による
IDの付け替わりが残る。[移行一覧](board-id-migration.md)を参照。
セルサイズ・外側余白の変更と、セル数を変えるリサイズを同じ保証として扱わない。
頂点塗り #29 も、この未解決の再採番経路を回避する角番号の補正には戻さない。
