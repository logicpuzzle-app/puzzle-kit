# 彫刻操作と盤面ID

対象: IsometricのBuild（3セルの反転）とCut（三角形による切断）。
[共通ID契約](board-id-contract.md)に従い、IDの文字列で形状・種類・端点を判定しない。
新しい操作を元グラフとともに保存する。旧彫刻データの由来を推測して移行するものではない。

## 編集と参照の寿命

- 入力先は現在の盤面の頂点ID。3枚の四角形と6個の外側頂点からなる対象を実際の境界で検証する。
  `cell-triangle-` 等の接頭辞を持つ四角形も対象であり、任意IDの三角形は対象外となる。
- Buildでは3セルと頂点のIDを維持し、中心頂点の位置とセル境界を変更する。
  同じ端点の組を持つ辺は同じIDを維持する。接続が変わる辺は別要素として新しいIDを発行する。
- Cutでは中心頂点と3個の元セルが消滅し、中央の三角形と3個の残りの三角形に新IDを発行する。
  元セルとの関係は`originalCells`に持つ。外周の頂点・辺と無関係なセルは再採番しない。
- 辺の比較には明確にエンコードした端点の組を使う。例えば`a`–`b-c`と`a-b`–`c`を混同しない。
  この比較キーを永続的な辺IDに流用しない。
- セル境界、辺・頂点・セルの隣接情報を同じ結果から更新する。
  保存時に存在しない辺や削除済み頂点を指す状態を残さない。
- 消滅したセル・頂点・辺の注記は、その種類付き参照に基づいて除去する。
  同じ文字列IDの別種類の要素には波及させない。問題／解答レイヤーと試行の注記を一体で扱う。
  この削除方針をPropertiesに表示し、Undo一回で元グラフと注記を戻す。
- 新規IDは操作を作る時だけUUIDで発行する。保存読込・履歴の再生では発行しない。
  Undo後の別編集では別のIDを発行し、取り消した操作の要素と混同しない。

## 保存・解除・他の編集との組合せ

形式1.8の`editBase / editOperations`に`kind: "sculpt"`を追加する。
操作にはモード・対象頂点・入力セル・新規セルID・新規辺のIDと端点を保持する。
読み込み時は元グラフから接続を再構成し、保存されたグラフと照合する。
IDの衝突や、記録した操作と異なる頂点位置・接続は読込エラーにする。

結合／分割と同じ順序付き操作列を使う。セルサイズ・外側余白の変更は元グラフも同時に変換し、
表示変形では元座標を保持する。表示番号や丸めた座標から参照先を作り直さない。

「彫刻を全解除」は記録された彫刻と、それに依存する後続操作を除き、元グラフから戻す。
独立した結合／分割は残す。削除した注記を全解除で自動的に復活させず、直前の操作をUndoした場合に復元する。
元形状を保持していない旧彫刻だけがある場合、全解除を無効にして理由を表示する。

## 検証と残る範囲

実ストアで任意ID、端点ペアの連結衝突、保存読込、Undo／Redo、Undo後の分岐、
同名のセル／頂点参照、試行、後続分割、サイズ・変形変更、全解除、不正な保存操作の拒否を確認する。
公開UIのPlaywright + ChromiumではBuild／Cutをマウス・タッチで実行し、
別の盤面を開いてから保存ファイルを読込み直す。失敗して元画面が残っただけの読込を成功とみなさない。
Before／Afterの画像・録画を残す。

旧再生成用`GridConfig.sculptOperations`だけから元の採番・注記を復元する移行と、
彫刻を含むIsometric盤面の行列・高さ・表示面変更は引き続き未対応。
保持した操作列を破棄して再生成する変更は受け付けない。
この段階は彫刻を含む全構造編集・全旧ファイルへの対応完了ではない。
