# 線入力の参照と操作仕様

基準: `ce30537`。IDの扱いは[盤面IDの契約](board-id-contract.md)に従う。
この文書は移行先の仕様を固定するもので、検証完了の宣言ではない。

## 操作の維持

- ジャンル別のツール一覧・初期設定は `src/constraints/schemas` と入力モードの定義を維持する。
  今回の変更でツールの追加・削除、問題／解答レイヤーの編集権限、ジャンルの判定規則を変更しない。
- 通常の線は選択中のcell／vertex／edgeへスナップし、許可された直交・対角方向の実接続を使う。
  同じ盤面・種類・IDを始終点とする線は作らない。ID文字列だけが同じ異種の点は別の点である。
- Halfは許可された異種の点間を結ぶ。直交はcell–edge、vertex–edge、対角はcell–vertex等の既存の接続規則を保つ。
- Straightは押下と解放の点を結ぶ1本の線。途中のスナップ点を経路に追加しない。
- Borderはvertex間、Wallは選択した辺そのものを参照する。
- 同色の線を逆向きになぞると消去する。保存された線レコードのID表記に依存しない。
  Shift、右ボタンの色、ドラッグ中の描画／消去モード、重なりの統合、Undo／Redoを維持する。
- 矢印の向きは入力の始点・終点を基準とし、IDの並び順や辺内部の頂点順で反転させない。

## フリーハンド

FreehandはスナップしないSVG座標の連続入力で、直交・対角・Straightとは排他。
距離が `FREEHAND_MIN_DISTANCE` 未満の移動を捨て、残る線分を同一strokeとして保持する。
Shiftで線分を追加せず、開始位置を進める。色・太さ・スタイル・矢印設定とstroke単位の選択を維持する。
`fromX/fromY/toX/toY` が位置の情報源であり、`from/to` のプレースホルダーを盤面IDとして解釈しない。

## 移行範囲

検索時に得た点の種類を開始点・補間経路・終了点・線データまで保持する。
参照モードは明示的な盤面設定から選び、Topology参照が欠けてもGrid形式を試さない。
ID・種類の一致と実際のMapを使い、未解決／曖昧な点では線を追加しない。
盤面や構造、編集レイヤーが変わった保留中の線入力は無効にする。

既存の型なし線は、辺参照または一意に特定できる端点を使って解決する。
混合端点の種類が曖昧なら順番にMapを探して決めない。
ネイティブ保存は端点の種類を保持し、Undo／Redoも線レコードと参照を一体で復元する。

## 必要な検証

- 公開File Openから、実位置と異なるGrid座標に見えるIDを持つ盤面で描画・消去・Undo／Redo・Save／Openする。
- 同じID文字列のcell／vertexを持つ盤面で混合端点の入力・描画・保存を確認する。
- 任意の線レコードIDで保存された線の消去と、矢印の入力方向を確認する。
- 正方形の長いドラッグ、非正方形、Half、Straight、既存の線重複・フリーハンドの回帰を確認する。
- Playwright + ChromiumのPCマウス／モバイルタッチで、同じ操作のBefore／After画像・動画を残す。

## 参照モード切替の移行

基準コミットの公開API `setUseTopology` は既存要素の参照を移行せずモードだけを切り替えていた。
Gridモードで作った型付き頂点線を保持したままTopologyへ切り替えると、
そのGrid IDが切替先トポロジに存在しない場合、線は未解決となり描画されない。
この経路をストアAPIと描画用resolverで再現し、
[参照モード切替](reference-mode-identity.md)として、注記・試行・設定・履歴を含む一体の移行を実装した。
通常の線入力のQAと、開発ハーネスでモードAPIを呼ぶQAは区別する。

明示的な対応表を検証できない形状・参照は、状態を変えず拒否する。
未解決時のID解析を復活させて回避しない。
他ジャンル・公開互換API等の移行が残るため、ID契約全体への対応完了とはしない。
