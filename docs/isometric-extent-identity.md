# Isometric盤面の行・列・高さ編集とID

面構成・内外表示を固定した通常のIsometric盤面（`gridType: 'iso'`）では、
行・列・高さを変更しても存続するセル・頂点・辺を再採番しない。
プレビュー、ストアのsetGrid/resizeGrid、公開resizeTopologyは同じ編集器を使う。

## 対応と寿命

セルは明示した`isometricFace`と面内の`index`で対応を検証する。
行列番号は面を跨いで重複するため、行列だけやIDの接頭辞で面を判別しない。
面情報のない旧ファイルは、宣言された設定から生成する全グラフと保存グラフを照合し、
頂点位置、セル境界・中心、辺の両端、各種類の隣接関係が一意に対応する場合だけ編集する。
照合は既知の格子の互換境界で行うものであり、座標を永続IDとして使うものではない。

- セルは同じ面内位置で存続する間、元のIDを保持する。外周境界の保存順も保持する。
- 頂点は存続セルの各角を通した対応が、旧→新・新→旧の両方で一対一の場合に存続する。
- 移動する面の接合部では、一つの頂点が二つに分かれたり複数の頂点が一つになったりする。
  この場合は元の頂点IDを廃止し、新しい頂点へ新IDを発行する。どちらかの面に注記を推測で移さない。
- 辺は同じ二つの存続頂点を結ぶ場合にIDと端点の向きを保持する。
- 新しく生まれる要素にはUUIDを発行し、既存IDを上書きしない。Undo後の再編集でも別の新IDを使う。
- 通常の外面表示では、側面の行番号は上端から数える。高さ追加は側面の下端へ追加する。
  内面表示でも同じ面内番号の規則を使うため、床との接合部が分離・統合する場合がある。

削除された要素の数字・塗り・線・頂点注記は、既存の種類付き参照の保持処理で除去する。
問題・解答、試行、盤面と履歴を一体で更新し、Undoは注記を含めて復元する。
UIはサイズ編集前に、削除セルと分離・統合される頂点の注記が消えること、Undoで戻せることを示す。

## 保存・除外・表示変形

ネイティブ保存は実グラフと任意ID、面情報を保持する。面情報は追加の任意フィールドであり、
旧ファイルを読むためにID表記を解釈しない。不正な面情報は読込で拒否する。
旧彫刻ファイルの厳密な移行照合は、面情報の存在しなかった旧writerのレコード形状を再現する。

除外元グラフを編集してから可視グラフを投影するため、除外中のセルのIDも保持する。
表示変形は元座標に戻して編集後に再適用する。高さ変更・除外解除・保存で元のセルを参照できる。

## 検証と未対応範囲

[実ストアテスト](../src/test/isometricExtentIdentity.test.ts)は任意IDの列編集・縮小・保存・試行・履歴、
高さ変更と除外・変形・境界順、接合部の注記除去とUndo、内面の部分面構成、未知形状の拒否を確認する。
[公開画面QA](../e2e/isometric-extent-identity.spec.ts)はPC・モバイルで行・列・高さ、
新セルへの入力、ファイル保存・読込、Undo、未対応形状のApply無効化を確認する。
これらはTopology参照モードの検証であり、旧Grid形式のセル・線入力全体を保証しない。

結合・分割・彫刻済みの盤面は、[元グラフと操作列の再適用](isometric-edited-identity.md)へ移行した。
既知の全グラフに一致しない独自形状のサイズ変更は未対応。
盤面・注記・履歴を保持して変更を拒否し、UIは理由を表示する。公開resizeTopologyはエラーを返す。
通常盤面の[面の表示・内外切替](isometric-faces-identity.md)も同じ編集器へ移行した。
未知の旧編集形状・他の未移行格子・分割端点を失う縮小は引き続き対応が必要。
この修正だけでIssue #29や全構造編集の対応完了とはせず、統合PRはDraftを維持する。
