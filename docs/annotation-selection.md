# 注記の選択とクリップボード

状態: 段階的に実装中。第1段階はMasterの注記選択・一括削除。
コピー／貼付と、線・ケージ・特殊図形を含む全要素への拡張は後続作業であり、完了扱いにしない。

## 選択の契約

- 選択は盤面（Grid設定・Topology・参照モード）、編集レイヤー、レコードの種類とIDで解決する。
  同じ文字列のセル／頂点や、数字／塗りのレコードを混同しない。IDの文字列解析は行わない。
- 第1段階の対象はセル塗り、頂点塗り、数字、セル／頂点／辺の記号。
  頂点塗りはGrid表示でも実Topologyの頂点を参照する。位置は現在の実データから取得する。
  曖昧な型なし記号、未解決・不可視・編集不能な注記は選択・削除しない。
- クリック／タップは近い配置点にある対象注記を選ぶ。同じ配置点の複数種類はすべて選び、
  個別の選択はPropertiesの一覧から行う。異なる配置点への同距離は推測せず選択しない。
- ドラッグは配置点が矩形に入る注記を選ぶ。Shiftは追加、空白クリックは解除。
  入力はpointerupで確定する。pointercancel・2本目の指・盤面／モード／レイヤー／ツール変更で
  保留中の矩形を取り消す。盤面変更後の古いイベントで選択を復活させない。
- 選択中の注記は盤面に表示し、書き出す画像・保存データには選択表示を含めない。
  パンモードは既存のパン操作を優先する。選択ジェスチャー中の複数指は選択を取消す。
- DeleteとPropertiesの削除は選択した種類・IDだけを消し、一回のUndoで全件を復元する。
  Undoで選択状態自体を復活させることは要件にしない。
- 特殊図形パネルの既存`selectedElements`とは独立した種類付き選択を用いる。
  旧文字列APIを全種類のレコードIDとして再解釈しない。

## コピー／貼付の設計（未実装）

コピーは種類付きの選択からスタイルと配置先をスナップショットする。
元盤面のIDを貼付先のIDとして使い回さない。貼付位置の基準点と種類を明示し、
現在の盤面への移動・別盤面への貼付は型付きの対応表を検証してから適用する。
同じ文字列・近い座標・境界配列の順番だけで対応を決めない。

全部の配置先が一意に解決した場合だけ、新規のレコードIDを発行して一括で貼り付ける。
範囲外・曖昧・非対応の要素があれば理由を示し、元データと貼付先を変更しない。
Cutはコピー成功後の削除を一つの履歴操作として扱い、Pasteも一回のUndoで戻る。
Playerは問題レイヤーを変更できない。選択やコピー自体は盤面の採番を変更しない。

## 回帰確認

実ストアで同名の別種類レコード、同名のセル／頂点、任意ID、Grid表示の頂点塗り、
未解決の参照、保留入力中の盤面変更、Undoと保存往復を確認する。
Playwright + Chromiumではマウス／タッチの範囲選択、個別選択、削除、履歴、画像出力を確認し、
Before／Afterの画像・動画を残す。コピー／貼付の試験は実装とともに追加する。
