# 除外を伴う旧結合・旧分割の移行

旧保存データでは、除外後のグラフに採番した頂点・辺IDを分割線が参照する。
除外設定だけを外して盤面を生成し直すと、同じIDが別の点・辺を指し、分割が失敗する。
従来は元グラフと編集操作も復元されず、SplitのRestore cellを使えなかった。

## 読込時の対応

`prepareLegacyEditedExclusions` は、保存された可視グラフ全体が指定設定の旧生成器と
一致する場合だけ適用する。IDの接頭辞や末尾、行列番号を解析しない。

1. 除外あり／なしの分割前グラフで、対象セル境界の端点・辺を明示的に対応させる。
   辺の向きが反転する場合は、辺途中の端点の比率も反転する。
2. 除外なしの旧グラフから結合・分割の元グラフと操作列を復元する。
3. この検証済みの旧形式境界内でだけ、元座標と端点ペアからID対応表を作る。
   保存済みのIDを優先し、保存されていない頂点・辺には衝突しない新IDを発行する。
4. 対応表を元グラフ・境界・分割対角線・操作列のすべてに適用し、除外を投影する。
   可視グラフの形状・ID・接続が旧出力と一致した場合だけ採用する。
5. 元グラフ・操作列・除外前グラフと正規化した設定を一体で保存する。
   可視セル・頂点・辺の既存ID、座標、並び、注記の参照先は変更しない。

Wave等は旧盤面の変形基準を、隠れている点と元グラフにも適用する。
非表示点の復元で既存の点を動かさず、Squareへ戻すときは復元済みの点まで表示範囲に含める。
解除操作で消滅する子セルの数字などは従来の編集方針で除去し、Undoでグラフと注記を復元する。
単純な除外移行へ構造編集を渡して分割IDを再解釈するフォールバックは行わない。

## 検証範囲と残り

固定の旧保存fixtureには、欠落した2セル、結合、辺途中からの分割、数字、頂点塗りを含めた。
読込直後の全セル・頂点・辺の一致、分割と結合の個別解除、除外解除、Undo/Redo、保存再読込を検証する。
追加のUnitはWaveの再適用とSquare復帰・レイアウト変更、結合セル全体の旧無効化、未知のグラフの保全を扱う。
Playwrightは公開File OpenからPCのマウス／ChromiumのPixel 7エミュレーションのタッチで分割を復元する。

除外セルを結合の構成員に含める場合や、除外解除で既存境界の細分化が必要になる場合など、
上記の全グラフ照合が成立しない旧盤面は未移行である。旧生成器が落とした盤外属性、
彫刻、由来不明の独自グラフ、既に別方式で保存された不完全な除外元グラフも別途対応が必要。
不明な対応を推測せず元の保存グラフを保持する。これらを解決済みとは扱わず、PR #126はDraftを維持する。
