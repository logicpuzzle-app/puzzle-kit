空の旧結合設定と除外セルの復元 Before / After

結合の全構成員が除外された同じ保存データを開き、Clear all excluded cellsを押します。Beforeは1セルのままです。Afterは元の3セルを復元できます。

Afterでは空の旧結合設定も整理し、復元した2セルを新しく結合できます。残る17と頂点塗りの参照先は変わりません。新規結合のUndo/Redo、保存・再読込まで確認します。

PCはマウス、MobileはPlaywright + ChromiumのPixel 7エミュレーションによるタッチです。物理端末ではありません。別実行のため操作時刻は一致しません。
