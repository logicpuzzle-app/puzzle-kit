LITSの実セル参照 Before / After

同じ任意IDの盤面を公開File Openから開きます。Beforeは正しいL字の解答をIncorrectと判定します。AfterはCorrect!と判定し、完成した部屋を強調表示します。

Afterでは部屋mapだけの読込から実境界を表示し、境界の削除・Undo/Redo・保存と再読込を確認します。部屋番号・盤面のIDを保持し、行列メタデータが欠ける場合は検証不能を表示します。

PCはマウス、MobileはPlaywright + ChromiumのPixel 7タッチエミュレーションです。物理端末ではありません。ファイルと画面操作を使い、アプリ内部の状態注入は行っていません。
