余白セルの旧分割の復元 Before / After

結合を経ずに余白セルを分割した、同じ旧保存データを開きます。BeforeはRestore cellが表示されません。Afterは元グラフと操作を復元し、分割を解除できます。

分割したセルの7は解除時に消え、別セルの9と17、頂点塗りは維持します。Undoで7と分割が戻り、保存・再読込後も同じ参照を保持します。

PCはマウス、MobileはPlaywright + ChromiumのPixel 7エミュレーションによるタッチです。物理端末ではありません。別実行のため操作時刻は一致しません。
