# 旧結合盤面のID移行

結合前のグラフがない旧ファイルでも、現在のグラフが既知の旧Grid生成器の出力と
一致する場合は、読み込み時に結合元を補完する。保存済みのセル・頂点・辺のID、
位置、形状、注記はそのまま保持する。以後はネイティブ形式1.4のmergeBaseとmergeGroupsを使う。

## 互換処理の境界

legacyMergesアダプターはGrid設定と表示プリセットから旧出力を生成し、
全要素のID・位置・境界・隣接・元座標と表示範囲を照合する。
一致を確認してから、その形式内だけで生成前後の頂点位置と辺の端点を対応付ける。
ID文字列は解析しない。独自のnativeグラフを、その形が似ているだけで旧形式とみなさない。

既存の頂点・辺は実際のIDを引き継ぐ。現在の盤面から消えていて復元が必要な頂点・辺に
だけ新しいUUIDを割り当てる。生成器の古い連番を再利用して、別の位置の要素を上書きしない。
元セルのID集合と、現在の結合セルのIDは明示的なoriginalCellsの対応から取得する。

## 旧結合の境界

旧生成器は外周の途中の頂点を取り除き、複数の辺を長い辺へまとめる。
さらに、結合グループが盤面全体を覆わない場合に最初の角も落とすことがある。
このため、二つの横並びセルを結合した部分が三角形になる旧データも存在し得る。

読込時に形状を作り直さないよう、結合セルの実際のboundaryを明示的に保存する。
この境界は元の外周頂点の巡回順の部分列でなければならず、外部の頂点・不一致の辺・
順序を入れ替えた接続を受理しない。長い辺や角を省いた対角辺は、結合元グラフ内に
復元用の境界データとして保持する。元セルの境界を構成する辺とは区別する。

解除したグループだけを元セルへ戻す。他の結合グループのID・形状・注記は変えない。
解除で長い辺が複数の元の辺へ分かれる場合、長い辺のIDをどれか一つへ使い回さない。
その辺や結合セル上の注記は削除し、Undoでは元の辺・セルと注記をまとめて復元する。
旧生成器が失った角は、解除するセルの形状として復元される。

## 対応範囲と失敗時

単純な結合集合がある、既知の旧出力に一致するグラフに対応する。
スナップショットのない従来形式も、旧生成器から読み込む境界で同じ移行を行う。
プリセットによる元座標が既知の出力と一致する場合も対応し、その後の表示変形、
セルサイズ変更、除外・復帰、再保存でも同じ結合元と実境界を保持する。

[既知の旧分割との混在](legacy-split-identity.md)は分割アダプターからこの処理を使用する。
除外済みの旧グラフ、彫刻との混在、既知の生成結果と異なる独自形状・元座標は
このアダプターの対象外。元の盤面を変更せず、復元できない結合の解除を無効にして理由を表示する。
旧ファイルを一律に再生成して「解除済み」とは扱わない。これらの移行と構造編集の残経路は継続課題。
