# 旧結合盤面のID移行

結合前のグラフがない旧ファイルでも、現在のグラフが既知の旧Grid生成器の出力と
一致する場合は、読み込み時に結合元を補完する。保存済みのセル・頂点・辺のID、
位置、形状、注記はそのまま保持する。以後はmergeBaseとmergeGroupsを使い、形式1.7では旧境界の走査情報も保持する。

## 互換処理の境界

legacyMergesアダプターはGrid設定と表示プリセットから旧出力を生成し、
全要素のID・位置・境界・隣接・元座標と表示範囲を照合する。
一致を確認してから、その形式内だけで生成前後の頂点位置と辺の端点を対応付ける。
ID文字列は解析しない。独自のnativeグラフを、その形が似ているだけで旧形式とみなさない。

既存の頂点・辺は実際のIDを引き継ぐ。現在の盤面から消えていて復元が必要な頂点・辺に
だけ新しいUUIDを割り当てる。生成器の古い連番を再利用して、別の位置の要素を上書きしない。
元セルのID集合と、現在の結合セルのIDは明示的なoriginalCellsの対応から取得する。

## 旧結合の境界

旧生成器は外周の途中の頂点を取り除き、複数の辺を長い辺へまとめる。
さらに、結合グループが盤面全体を覆わない場合に最初の角も落とすことがある。
このため、二つの横並びセルを結合した部分が三角形になる旧データも存在し得る。

読込時に形状を作り直さないよう、結合セルの実際のboundaryを明示的に保存する。
単純な旧境界では、元セル集合の境界ループのいずれか一つについて、頂点の巡回順の部分列でなければならず、外部の頂点・不一致の辺・
順序を入れ替えた接続を受理しない。長い辺や角を省いた対角辺は、結合元グラフ内に
復元用の境界データとして保持する。元セルの境界を構成する辺とは区別する。

解除したグループだけを元セルへ戻す。他の結合グループのID・形状・注記は変えない。
解除で長い辺が複数の元の辺へ分かれる場合、長い辺のIDをどれか一つへ使い回さない。
その辺や結合セル上の注記は削除し、Undoでは元の辺・セルと注記をまとめて復元する。
旧生成器が失った角は、解除するセルの形状として復元される。

## 離れた構成員・角接触・穴を持つ旧結合

旧生成器は、離れた構成員や穴のある集合でも、一つの境界だけを結合結果として保存することがあった。
全グラフが既知の旧出力に一致する場合、保存済みの境界をそのまま保持し、表示されなかった構成員も
元グラフに記録する。読込時に欠落部分を描き足したり、凸包へ置き換えたりしない。
解除は全構成員を元のセルIDで復元する。消えた結合上の数字は削除し、存続するセルの数字・頂点注記は保持する。
Undo/Redo・保存再読込で同じ対応を戻す。

通常の結合は、元セルを辺の共有関係で連結成分に分け、その成分ごとに境界ループを検証する。
単純な旧境界もこの規則で読める。共有頂点を繰り返す旧出力や、一つの辺連結成分内で分岐する
元境界については、既知の旧生成器が実際にたどった閉じた経路を `boundary.sourceWalk` に保持する。
`vertices` と `edges` は元グラフの実ID参照であり、頂点が複数回現れても別のIDを発行しない。
走査順は互換処理で既知の旧出力を再現するためのもので、アプリがIDの文字列から推定する規則にはしない。

読込時には、経路が閉じ、各辺が隣り合う頂点を結び、結合元セル集合の実際の外周辺であり、
同じ元辺を二度使っていないことを検証する。保存された表示境界はその経路の巡回順の部分列でなければならない。
頂点の反復は出現位置ごとに照合する。異なる経路への飛び移り、不正な端点や内部辺の使用、
必要な経路情報の欠落を、ID解析や座標の近さで補わない。不正なnativeファイルは現盤面を壊さず拒否する。
元経路の一部だけを表示していた旧仕様も保持し、読込時に描き足したり凸包に置き換えたりしない。

形式1.7に経路を保存し、分割・除外を伴う移行でも元頂点・元辺の対応表を同時に適用する。
頂点の隣接セル一覧には、その頂点を複数回通るセルでも一度だけ登録する。
通常の新規結合には旧経路を付けず、非連結・角接触だけの接続・穴・分岐を持つ境界は引き続き拒否する。

行列追加等で構成員が全員変わらず残る場合は、元集合の非連結だけを理由に結合IDを変えない。
構成員が欠ける場合は保存境界の指定を外し、残存する元セルの接続と役割から境界を更新する。
除外付きの旧移行でも同じ規則を適用する。

## 余白セルと結合結果の役割

旧生成器は余白の盤外セルと盤内セルを結合でき、その出力の盤外属性を落としていた。
検証済みの旧境界には、必要な場合だけ `boundary.outboard` を明示する。
出力セルの役割と元セルの役割を分離し、結合状態では保存時の盤内セルを保ち、解除すると
同じIDの余白セルを盤外として戻す。存続していた別のセルの役割は保存済みグラフを優先する。
新規の通常結合にはこの情報を付けず、盤内・盤外の混在は引き続き拒否する。

この情報は結合後の分割、除外を伴う旧移行、ネイティブ保存・読込にも引き継ぐ。
明示した役割の型や、操作を再生した結果と保存グラフの役割が食い違うファイルは適用しない。
構成員がすべて存続する行列追加では役割差だけを理由に結合を分断しない。
構成員が失われる縮小では従来どおり接続と役割に応じた分割を行う。
元の境界に戻す際、消える分割点・長い辺の注記は元の別要素へ付け替えず、Undoで復元する。

## 対応範囲と失敗時

元セルの境界を単純ループまたは明示した旧経路として検証でき、既知の旧出力に一致するグラフに対応する。
スナップショットのない従来形式も、旧生成器から読み込む境界で同じ移行を行う。
プリセットによる元座標が既知の出力と一致する場合も対応し、その後の表示変形、
セルサイズ変更、除外・復帰、再保存でも同じ結合元と実境界を保持する。

[既知の旧分割との混在](legacy-split-identity.md)は分割アダプターからこの処理を使用する。
除外済みの旧グラフ、彫刻との混在、既知の生成結果と異なる独自形状・元座標は
このアダプターの対象外。元の盤面を変更せず、復元できない結合の解除を無効にして理由を表示する。
旧ファイルを一律に再生成して「解除済み」とは扱わない。これらの移行と構造編集の残経路は継続課題。
