# 結合済み盤面の行列編集とID

正方・六角格子の結合元グラフを検証し、その実際のセル・頂点・辺を使って行列・周囲セルを増減する。
`merged-N`の解析や現在の位置からのID再発行は行わない。
新規の結合と、[既知の旧結合ファイルの移行](legacy-merge-identity.md)で保持した結合元が対象。
UIのプレビュー・適用、`setGrid`・`resizeGrid`、公開の`resizeTopology`は同じ編集器を使う。

## 結合セルの寿命

| 変更 | ID・形状・注記 |
| --- | --- |
| 行列追加、結合対象外の行列削除 | 結合ID、元セル集合、境界IDを維持。注記を維持し、中心はサイズ・余白の移動に合わせる |
| 一部を切り落として一つにつながる場合 | 同じ結合セルとしてID・数字を維持。残った元セルと辺から境界・中心を更新する |
| 元セルが一つだけ残る場合 | 結合IDを維持し、`mergeGroups.cellIds`に一つの元セルIDを保持。明示的な解除では、その元セルを復元する |
| 複数に分断される場合 | 元の結合IDは廃止し、各断片へ新しいIDを発行。数字・セル塗り等をどちらかへ推測で移したり複製したりしない |
| 全部が削除される場合 | 結合セルと参照する注記を除去する |

断片は元セルの**辺の接続**で決める。角で接するだけでは同じセルにしない。
周囲セルと通常セルが混在するようになった場合も、その境界で分ける。
分断した元セルが非表示・無効・外周扱いだった場合、その指定は各断片へ引き継ぐ。

残る頂点・辺はIDを維持する。注記を削除するのは実際になくなる要素だけであり、
隣のセルが消えたという理由で共有境界の注記まで消さない。
問題・解答レイヤー、試行、選択、解答対象等をグラフと一緒に更新する。
Undo/Redoは編集前後の形状・ID・注記・試行を一体で復元する。
削除後に別のセルを追加しても、削除済みIDを別の要素へ再発行しない。

ネイティブ形式1.4の`mergeBase / mergeGroups`でこの関係を保存する。
単一元セルを持つ結合グループも読込・解除できる。空のグループは受け付けない。
行列設定の`mergedCells`と実際のグループ情報は同時に更新する。

## 旧形式・表示変形

旧結合の長い辺・斜めの辺は元格子の辺とは別に保存されている。
格子の編集は元セルを構成する辺だけで行い、変更されない結合の特殊な境界は同じID・形状で残す。
切り落とされる結合の境界は残った元セルから作り、使わなくなる長い辺の注記は削除する。
そのIDを短い辺に流用しない。旧形式の角欠けも、変更されない結合ではそのまま保持する。

Wave等の表示変形中も保存された元座標に対して編集してから表示変形を適用する。
表示範囲の変化により見た目の変形は変わり得るが、参照先のIDは変わらない。
六角格子の上側余白で行のずれが変わる場合は`hexRowOffset`も保存する。

## 検証と残る範囲

実ストアのテストは正方・六角の拡張、共有境界、非表示・Wave・サイズ・余白・保存の組合せ、
U字形の分断、単一元セルへの縮小、注記・試行のUndo/Redo、旧形式の長い境界を確認する。
公開UIのPlaywright + Chromiumでは列追加とU字形の分断を操作し、Before/After画像・動画を残す。

独自の元グラフ、正方・六角以外の格子、分割・彫刻を伴う結合は未移行。
行列と結合指定など複数の構造設定を同時に変更するAPIにも旧生成経路が残る。
これらでのID保持を保証するものではなく、PR #126はDraftを維持する。
