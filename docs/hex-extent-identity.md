# 正方・六角格子の行列編集とID

正方格子と正六角格子は、保存中の実グラフを同じ編集器で拡張・縮小する。
格子の設定からIDを再生成せず、存続するセル・頂点・辺のIDを保持する。
セルの明示的なindex、実際の座標と境界・接続が対象格子に一致することを検証してから編集する。
編集中の格子上の位置は一時的な対応付けにだけ用い、永続IDや欠損参照の補完に使わない。
セル境界配列の循環移動・逆順を許容し、配列の何番目かを恒久的な頂点参照にしない。

行数・列数の変更は下・右へ追加または削除する。上・左の周囲セル数を変える場合は、
存続要素をその分だけ移動する。新しい要素にだけUUIDを発行し、縮小後の再拡張でも
削除済みIDを別要素へ戻さない。残ったセルの共有辺・共有頂点は削除しない。
消滅した要素の線・数字・頂点注記等は参照フィールドから整理し、両レイヤーと試行を
トポロジと一緒にUndo/Redoする。表示番号とIDを混同しない。

## 六角格子の行のずれ

六角格子の各行は半マスずれている。上に奇数行を追加しても存続セルの接続を変えないよう、
どちらの行をずらすかを`GridConfig.hexRowOffset`（0または1、旧形式の省略時は0）で保持する。
これは盤面全体の配置情報であり、セル・頂点のIDではない。

上の周囲セル数の増減に応じてこの値を更新し、Grid設定とトポロジのsourceConfigを
ネイティブ形式1.3へ保存する。通常の行数変更は下側なのでこの値を変えない。
従来Grid描画でも、同じ周囲セル数と行のずれを描画位置・ヒット判定・表示範囲に適用する。
保存設定、実グラフ、除外前のグラフで値が不整合なファイルは読込を失敗させ、現行盤面を保つ。

## 表示変形・除外・公開API

元座標を保持しているWave等の変形済み盤面では、元の実グラフを編集してから変形を再適用する。
除外中のセルは保持したexclusionBase側も編集し、解除で同じIDへ戻す。
setGrid・resizeGrid・プレビュー・公開resizeTopology/expandTopology/shrinkTopologyは、
適用可能な正方・六角格子で同じ編集器を用いる。

六角格子の頂点・辺には一意な整数の行列番号を保証できないため、編集後のindexはnullとする。
位置はposition/midpoint、接続は明示的な境界・隣接フィールドで取得する。
セルのindex [row,col] は現在の配置を保持し、上・左の追加時は変わる。

## 未対応範囲

三角格子・その他の格子、独自形状、結合・分割・彫刻を伴う構造変更の再生成経路は未移行。
格子設定がsquare/hexでも、実際のグラフが規則的な格子ではない場合に推測で対応を付けない。
元座標のない旧形式の変形済み盤面も、形状の一致を検証できなければこの編集器の対象外になる。
既存の代替経路にはID再割当ての課題が残るため、頂点塗りPRのマージ準備完了とはしない。
