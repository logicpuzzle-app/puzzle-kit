# 変形プリセットと盤面ID

Wave・Cylinderなどの表示変形は、現在のグラフの座標だけを変える。
セル・頂点・辺のID、境界配列と接続、問題・解答・試行内の参照を作り直さない。
格子設定から再生成すると消えていた任意IDの独自盤面も、そのまま変形する。

各セルの`baseCenter`、頂点の`basePosition`、辺の`baseMidpoint`と、
トポロジの`deformationBounds`に変形前の座標を保存する。
これらは座標データであり、IDの代用や欠損参照の推測には使用しない。
再適用や他のプリセットへの変更は同じ元座標から計算し、変形を重ね掛けしない。
Square / Pyramidの無変形へ戻すと元座標を復元して補助データを外す。

除外中のセルは`exclusionBase`にも元座標を保持し、表示中の要素と同じ変換を適用する。
セルサイズ・外側余白を変更すると、現在座標と元座標の両方を同じ比率で更新する。
Undo/Redoは元座標を含むトポロジと、適用したプリセット設定を一緒に復元する。
形状だけの変更もプレビュー・Apply・Cancelの対象になる。

保存形式1.3にはこれらの任意フィールドを含める。読込時は有限な座標と完全性、
除外前後で同じ要素の元座標が一致することを検査する。
変形範囲があるのに一部の元座標が欠けるファイルは、現行盤面を置き換えず読込を失敗させる。
過去の保存データに元座標がない場合は、保存済みの実際の形を新たな基準にする。
格子設定から過去の形状を推測しないため、古い変形ファイルから変形前の形を復元することは保証しない。

この変更は接続を変えない表示変形が対象。
[正方・六角格子の行列編集](hex-extent-identity.md)も元座標を使ってIDを保持する。
その他の格子、結合・分割・彫刻の再生成とID寿命の移行は引き続き未完了。
行列変更を同時に行う操作も、対応済みの編集経路以外では残課題に含む。
