# 編集済みIsometric盤面の行列・面編集

[ID契約](board-id-contract.md)と[通常Isometricの編集](isometric-extent-identity.md)に従う。
対象は、検証できる通常Isometricの元グラフと、保存された結合・分割・彫刻操作を持つ盤面。
操作済みの形状を通常格子に置換せず、元グラフを面ごとに編集して操作列を再適用する。

## 同一性と依存関係

- セル・頂点・辺の存続は、元グラフについて通常Isometricの規則で判定する。
  保存された元セルの境界順は、検証済みの面・格子の対応の中だけで使う。
  任意の結合セルの角番号やID文字列から対応を推測しない。
- 結合セルは、残った構成セルが一つの連結領域なら元IDを保持する。
  面の移動で領域が分離した場合は元IDを廃止し、各領域に新IDを発行する。
  元のセル注記をいずれかの領域へ自動で移さない。
- 分割の端点は、対象セルの元セル集合と、元グラフの明示的な角対応から解決する。
  同じ旧頂点が面ごとに分離しても、対象セルの境界で一意に対応する場合は分割を維持する。
  子セルIDは保持するが、端点が変わる分割辺には新IDを発行する。
  旧頂点・旧辺の注記を新しい要素へ付け替えない。
- 彫刻は支点と入力セルが存続し、操作を再適用できる場合に保持する。
  支点・入力セルがなくなる場合は彫刻を取り消す。回転がセルIDを維持していても、
  その形状に依存する後続の分割・結合・彫刻を取り消す。独立した操作は残す。
- 注記と試行の参照を同じ編集で更新し、Undoでは盤面・設定・注記・試行を一体で戻す。
  設定側の彫刻操作も更新する。グラフだけ更新すると、保存時に両者が食い違うためである。

## 位置と面の非表示

面ごとに移動量が違うため、盤面全体に一つの移動量を適用しない。
結合・分割セルのラベル位置は、対応する全境界が一つのアフィン変換で移り、
変換後のラベルがセル内にある場合に保持する。それ以外は新しい領域内に位置を求める。
彫刻の中心位置は、その操作の形状から再計算する。

面の所属は、元セルの明示的な面と保存済み操作から求める。
結合は構成セルの面の集合、分割は親の面を引き継ぐ。
彫刻の回転セルと切断の中央セルは入力した3セルの面の集合、切断の残片は各入力セルの面を持つ。
`originalCells`の形式差や出力IDの表記には依存しない。

複数面にまたがるセルは、関係する面を一つでも隠すとセル全体を非表示にする。
暗黙にセルを分割しない。非表示グラフと注記は保存し、すべての面を表示すると復元する。
非表示中も元グラフのサイズを編集できる。

## 適用できない場合

元グラフを通常Isometricとして一意に検証できない場合、移動後に分割端点が一意に
対応しない場合、あるいは操作の再適用に失敗する場合は、編集全体を拒否する。
現在の盤面・設定・履歴を変更しない。公開resize APIも失敗を返し、再生成へ逃がさない。

未知の旧形状、追加された旧境界プリミティブ、新たな境界との交点が必要になる分割の縮小は
この処理で対応済みとはしない。これらの対応は継続課題であり、拒否だけで移行完了とは扱わない。

## 検証

[実ストアテスト](../src/test/isometricEditedExtent.test.ts)で、屋根の結合と壁の分割の異なる移動、
接合部の辺ID変更、非表示中の編集・保存、彫刻の維持と依存操作の取消、
分離した結合セルの注記削除、Undoと試行の復元を確認する。
[公開画面のE2E](../e2e/isometric-edited-extent.spec.ts)は、結合と分割の混合盤面・彫刻回転・切断を
PCとモバイルエミュレーションで編集し、ネイティブ保存と面の非表示・復元を確認する。
