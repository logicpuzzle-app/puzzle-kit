# キーボード記号入力の参照

セルカーソルでの記号入力・削除は、[盤面IDの契約](board-id-contract.md)に従う。
対象は `cursorCell` が参照する現在の盤面のセルであり、同じ文字列の頂点・辺とは区別する。

- `.` / `?` は配置先の `pointType: 'cell'` を明示して保存する。
  同じセルにある既存のテキスト記号は置き換え、同名IDの頂点テキストは変更しない。
- Delete / Backspace は、そのセルに属する記号だけを削除する。
  型なしの旧記号は参照が一意な場合のみ対象とし、cell / vertex 等が重複する参照は削除しない。
  同じセルに複数の記号がある場合の既存の「1件ずつ削除する」動作を維持する。
- 対象セルが存在しない場合は入力・削除を行わない。
  Topologyモードで盤面が欠けた場合、矢印キーもGrid参照へフォールバックしない。
  盤外セルは既存のツール・レイヤーの編集方針に従う。
- 移動はTopologyの実際の隣接関係と位置を使う。Gridモードでは既知のGridアダプターを使う。
- Undo / Redo とネイティブ保存・復元では記号のレコードID、配置先ID、種類を保持する。

修正対象は共通の `useKeyboardShortcuts`。盤面IDの採番・寿命は変更しない。
型なし旧記号のデータ全体を、この入力経路で一括移行することはない。
実ストアのフックテストで同名ID・曖昧参照・参照先欠損を検証し、Chromiumでは
公開File Openから入力・削除、Undo / Redo、File Save / Openを確認する。

汎用選択ツールの頂点塗り対応と要素のコピー／貼付は別の未完了項目。
現状のメニューには要素のコピー／貼付の実装がなく、この修正で対応済みとはしない。
