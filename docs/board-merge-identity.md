# セル結合とID保持

新しい結合操作は現在の実グラフを編集する。結合前の実グラフを`mergeBase`、
結合セルのIDと元セルのID集合を`mergeGroups`へ保存する。`merged-番号`を
配列の添字として解釈しない。ネイティブ形式1.4はこの情報も保存・復元する。

## 要素の寿命

- 結合対象外のセル、残る境界頂点・辺は同じIDと位置を維持する。
- 外周の途中にある一直線上の頂点も残す。見た目が同じでも別の長い辺へ置換しない。
- 結合セルだけに新しいUUIDを発行する。結合セルをさらに結合するときも新しいIDにする。
- 内部になった頂点・辺と元セルは表示グラフから外れ、結合前のグラフに保持される。
- 解除は保存した同じ元セル・頂点・辺を復元する。独立した他の結合セルを再採番しない。
- 境界が複数の輪になる結合、穴を持つ結合、角だけで接する結合、外周セルと通常セルの混在は受理しない。
  最大の輪や凸包に置き換えて形状を推測する処理は行わない。

元セルや消える内部境界を参照する数字・線・塗り・頂点注記等は結合時に除去する。
配置先を新しい結合セルへ推測で移さない。問題・解答両レイヤー、試行、グループ、
解答対象セル等を同じ処理で整理し、Undo/Redoはグラフ・注記・試行を一体で復元する。
解除は形状だけを復元する。除去した注記も戻す場合は結合操作のUndoを使う。
この違いは結合のプロパティパネルに表示する。

## 他の操作との組合せ

除外・解除、セルサイズ・外側余白変更、Wave等の表示変形は結合前のグラフにも適用する。
結合・解除自体は表示変形をかけ直さず、現在の位置を維持する。
新しい結合の描画中心には元セル群の中心を用い、形状の外になる場合は元セル内の中心を使う。
結合セルのindexはnullであり、永続的な参照はIDから解決する。

右クリックとプロパティパネルの解除は同じ操作を呼ぶ。
`setGrid({ mergedCells })`のみを変更するAPIも明示的な元セル集合を使い、
同じ集合の結合セルを維持する。解除のために設定から盤面を生成し直さない。
読込時は現在と結合前のグラフ、除外前のグラフ、Grid設定の結合集合の整合を検証する。
不整合なら読込を拒否し、編集中の盤面を保持する。

## 残る移行

結合前のグラフを持たない旧ファイルは、[既知の旧生成器と照合する移行](legacy-merge-identity.md)で対応する。
旧出力と一致しない独自グラフや、除外・分割・彫刻を伴う旧ファイルの移行は未完了。
対応不能な盤面をGrid設定から推測して再生成せず、解除できない理由をプロパティに表示する。
旧生成器による初期化・互換処理自体は残っている。

結合後の行列変更、分割・彫刻との組合せ、複数の構造設定を同時に変えるAPIにも
再生成する経路が残る。この修正だけで全構造編集のID保持が完了したとはしない。
残る構造編集の移行を終えるまで、PR #126はDraftのままとする。
