# 頂点を中心とする塗り（Issue #29）

状態: 実装・QA中。既存の盤面再生成経路のID保持が未完了のため、マージ準備完了ではない。

## 操作と意味

MasterのSurface > Fill / Dotで、Propertiesの塗る対象をCell / Vertexから選ぶ。
Paint・Edit・PlayerでもShade / Unshadeの下に同じ切り替えを表示する。
初期値はCell。Vertexはセル中心を通るループの内外を塗り分けるための注記であり、
セルの黒マス・白マスや解答判定の入力には数えない。セル用の非隣接制約も適用しない。

頂点をクリック・タップして塗り、ドラッグで連続入力する。
同じ色・表示形式で再入力すると消去し、Shiftでも消去できる。右クリックは副色を使う。
FillとDot、別の色への変更は既存の注記を置き換える。ドラッグは1回のUndoで戻る。
問題／解答レイヤー、表示切り替え、Undo/Redo、試行の取消、解答全消去に対応する。
Playerは解答レイヤーだけを編集する。

## 描画範囲

隣接する各セルの多角形を、その境界頂点のうち対象頂点が最も近い領域で切り抜き、
それらを合わせて描画する。正方格子では頂点を中心とした双対格子の四角になる。
除外・盤外セルには描かず、盤面外へはみ出さない。Dotも同じ領域でクリップする。

これは本実装の描画方針であり、penpa-editの実装を移植したものではない。
正方格子と独自の六角形fixtureでPNG出力の画素を検証している。
任意の凹多角形・自己交差する変形について正しい双対領域を保証したものではない。

## ID・保存・履歴

`PuzzleElements.vertexSurfaces`に`id / vertexId / layer / color / displayMode`を保持する。
セルの`surfaces`とは別に保存する。配置先は現在のトポロジの`vertices.get(vertexId)`で解決し、
IDの解析・位置の推測・セル境界の配列添字による代替参照をしない。
参照不明な注記は保持して描画せず、新規入力では未解決の頂点を拒否する。

ネイティブ形式は1.3.0。旧形式も読み込み、グラフがない場合だけ読込境界で生成する。
従来Grid描画モードでも頂点用の実グラフを保持・保存する。
このモードの除外IDは互換アダプターで明示した行列番号に解決し、周囲セルのオフセットを
適用して実グラフへ投影する。列追加で新しいセルがUUIDを持っても除外・解除できる。
共有URLとJSONにグラフ・頂点参照を含め、PNGには表示状態を反映する。
旧バージョンのアプリで開いて保存し直した際の注記保持は保証しない。
外部パズル形式への頂点塗り変換は実装していない。

存続する頂点のIDは、対応済みの正方・六角格子の行列変更・セルサイズ変更・余白変更で保持する。
除外解除で元の頂点へ戻り、完全削除された頂点の注記は除去する。
Undoはグラフと注記を一体で復元する。表示番号とIDは別データである。
[共通ID契約](board-id-contract.md)と[正方・六角格子の行列編集](hex-extent-identity.md)も参照。

## マージ前に解消する課題

三角格子など他の格子の行列変更、独自盤面の構造変更、結合・分割・彫刻では、
従来の再生成経路が残る。同じ文字列の頂点IDが別の位置に割り当てられる可能性があり、
`Map.has(id)`だけではその誤りを検出できない。描画側で近い頂点へ付け替えて隠す方法は採らない。
各操作で存続・新規・削除の対応を定義し、全参照と履歴を更新する必要がある。

`a840e7a`の実ストアを使った追加調査で、次の2件を再現した。

- 2×2の六角格子を3列に増やすと、下端の頂点IDが約(54.64, 90)から(123.92, 30)へ移り、注記が別の場所を参照する。
- 任意IDの保存fixtureへWaveプリセットを適用すると、`crossing|center`が新しいグラフから失われる。

Wave適用は[表示変形のID保持](board-preset-identity.md)、六角格子の行列変更は
[正方・六角格子の共通編集](hex-extent-identity.md)で修正した。
他の格子や結合・分割・彫刻など、再生成を行う未対応操作が残る限りDraftを維持する。

従来Grid形式のセル・線とTopology形式のセル・線は参照体系が異なる。
今回、頂点参照用グラフはモード変更で作り直さなくなったが、既存セル・線を含む
両形式間の全面的な移行が完了したわけではない。

汎用の選択・クリップボード編集への追加は未実装。既存の選択機能自体も対象が限定される。
大盤面・複雑な凹形状の操作性能と描画は追加QAが必要。

新規のセル結合・解除も[実グラフを保持する方式](board-merge-identity.md)へ移行した。存続する境界頂点の注記を保持し、内部に消える注記はUndoで復元する。旧結合ファイルの移行と結合後の行列・分割・彫刻は未完了。
