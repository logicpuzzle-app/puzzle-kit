# Kakuroの参照・編集契約

[盤面IDの契約](board-id-contract.md)をKakuroの入力・描画・判定にも適用する。
セルを識別する `cellId` とヒントレコードの `id` は別のキーである。
表示用の行列番号を変更しても、存続セルとそのヒントを再採番しない。

## 対応する盤面

正方格子の盤内セルを対象とする。Topologyモードではセル・頂点の明示的な行列情報と
実際の境界・隣接参照を使い、座標に似たIDも不透明な文字列として扱う。
境界配列の開始位置からヒントの上下左右を推定しない。
表示変形と余白の追加後も、同じセル参照と論理的な右・下の方向を維持する。

Gridモードは明示した互換境界で行列とセルを対応させる。
保持中のTopologyに同名IDがあるかどうかを分岐条件にしない。
結合・分割などで正方格子の対応を確認できない場合や、必要な参照・行列情報が欠ける場合は
判定不能とする。盤外ヒント、puzz.link/Penpa形式の入出力はこの対応範囲に含めない。

## 入力と保存

- 選択したセルIDを入力先にする。選択の行列からIDを再構築しない。
- 同一セルの横・縦の和は独立して編集する。空欄と0は和の制約を持たない。
- 不明・無効・盤外の対象は変更しない。数字の削除とヒントの設定は一回のUndoで復元する。
- 新規ヒントのレコードIDを配置先IDから導出しない。読み込んだ別のヒントを上書きしない。
- 行列の縮小で削除されたセルのヒントも削除し、Undoで参照ごと復元する。
  一時的な除外では解除時に戻るヒントを保持する。描画できないことだけでは保存データを削除しない。
- モード切替は既存の原子的な参照移行を使い、保存・Undoではモードとデータを一緒に戻す。

## 判定

同じ実セル集合で横・縦の連続区間を作り、重複、合計、未入力を検査する。
除外セルや穴で区間を区切り、その向こうのヒントを拾わない。
誤りの位置は実際のセルIDで返す。ヒント・数字の参照が不明または同一セルへの記録が曖昧なら、
配列の最初の候補を採用して正解にはせず、Undecidedとして返す。

テストは任意IDの実盤面の入力・描画・判定・保存、余白変更とセル削除の履歴、
レコード衝突、Gridモード、未解決参照を扱う。生成器の連番順は固定しない。
