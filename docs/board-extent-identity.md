# 正方格子の行列編集とID

[ID契約](board-id-contract.md)に沿い、正方格子の行列数・周囲セル数の変更を
既存のグラフの編集として扱う。生成器の連番へ参照を付け替えない。

## 操作の意味

- 行列数の変更は下端・右端を増減する。
- 上・左の周囲セル数を変更すると、既存セルの行列番号と描画位置は移動する。
  セルとその境界のIDは維持する。
- 削除セルに接する頂点・辺でも、残るセルが使うものは存続する。
- 新規要素にはUUIDを発行する。縮小後に拡大しても、削除済みIDを復活させない。
  Undo/Redoでは保存した同じ要素を復元する。
- 一時的に除外したセルも保持盤面上で編集する。除外解除・保存し直しを経ても
  残るセルと参照先のIDは変わらない。

実装は[resizeSquareExtent](../src/utils/topology/squareExtent.ts)。
操作中だけ使う格子スロットに、実在するセル・頂点を配置して編集する。
このスロットは永続IDではなく、保存もしない。IDの解析、頂点indexの丸め、
セル境界配列の何番目かによる恒久的な頂点の特定は行わない。
辺は明示的な両端頂点で確認し、存続する辺の向きも維持する。

## 適用条件と未対応範囲

この編集器が受け付けるのは、正方形プリセットの完全な矩形正方格子。
各セルの明示index、四隅の実位置、境界辺の接続、全要素数を検証する。
非表示セルがある場合は除外前の保持盤面を使う。古い保存データの除外は
[既知の旧形式の変換](board-cell-exclusion.md)を先に行う。

独自形状、indexのないセル、非正方格子、変形プリセット、結合・分割・彫刻を
この条件だけで再解釈しない。編集器は `null` を返す。
**現時点のストアでは未対応盤面は従来の再生成経路に進むため、その経路のID保持は
未修正。全格子のリサイズが安全になったという保証ではない。**
公開の `resizeTopology / expandTopology / shrinkTopology` にも従来処理が残る。
これらと、プリセットの再適用による再生成は次の移行対象。

## 注記・履歴

ストアの `setGrid`（プロパティ画面）と `resizeGrid` は同じ編集処理を使う。
プレビューでも存続IDを引き継ぐ。適用時に行列数・トポロジ・両レイヤー・
試行中の保存状態・選択をまとめて更新し、同じ単位でUndo/Redoする。
縮小前には、範囲外の数字・線・塗りが削除されることを画面に示す。

[注記の整理](../src/utils/topology/retainedElements.ts)は実際に削除された要素を
参照する数字・塗り・線などを除く。隣のセルが消えただけの線は除かない。
線グループ・部屋マップ・解答領域・複色塗りも整理し、未知のIDを別の要素へ
付け替えない。対象種類を持たない既存の記号・点列は、現行描画器と同じMapの
検索順で扱う。この旧データモデルの曖昧さ自体は別途解消が必要。
任意のジャンル固有拡張データ内の参照までは自動変換しない。

## 回帰確認

[Unit](../src/test/boardExtentIdentity.test.ts)は不透明なIDの盤面を用い、
列の追加・削除、共有境界、削除IDの非再利用、保存、Undo/Redo、除外中の
上・左への拡張、試行状態の復元を確認する。
[E2E](../e2e/board-extent-identity.spec.ts)はPCとモバイルChromiumで列数を変更し、
線・数字・塗りの表示、追加セルへの入力、保存し直し、Undo/Redoを確認する。
採番アルゴリズムの結果をテストに複製しない。
