# セル除外とIDの寿命

[ID契約](board-id-contract.md)のセル除外を、Topologyモードでは次のように実装する。
除外は一時的な非表示・無効化であり、盤面要素の完全削除ではない。

- 初回除外の直前の盤面を `exclusionBase` に保持する。セル・頂点・辺のID、位置、接続はその盤面を正本とする。
- Voidは対象セルを表示・操作用の盤面から外す。残ったセルに必要な頂点・辺だけを同じIDで残し、隣接情報を更新する。
- Outboardはセルをヒント領域にし、通常セルの隣接判定から外す。元から外周にあるセルの属性は維持する。
- 再表示は保持した盤面から同じ要素を戻す。除外順に依存した採番やIDの解析を行わない。
- 非表示要素への線・塗り・数字の参照は両レイヤーに保持する。描画対象に存在しない要素は表示せず、別の要素へ付け替えない。
- すべてのセルを除外しても盤面の描画範囲は保つ。穴を再クリックする位置が変わらない。
- 除外・解除・一括解除は盤面と設定を一体で履歴に記録する。ドラッグ操作は既存の履歴グループにまとめる。
- ネイティブ保存・読込、自動保存、共有データには非表示要素も含める。

`exclusionBase` は1段だけ保持する。再度の除外で入れ子に増やさない。
読込時は基盤面自身の参照整合性に加え、表示中のセル・頂点・辺が基盤面と同じIDで
同じ位置・境界・端点を指すことを検証する。不一致なら読込を失敗させ、現在の盤面を保持する。

## 従来データ

除外前の盤面が保存されていない従来データには、専用の互換処理を使用する。
入力が既知の生成器の結果と同じID・位置・セル境界・辺端点を持つ場合に限り、
生成器の境界順序を使って除外前の盤面へ対応付ける。生きているIDと位置を優先し、
従来ファイルに記録のない頂点・辺には新しいIDを発行する。
この境界順序は互換処理内だけの対応情報であり、永続的な頂点識別子ではない。

任意の編集済み盤面で、非表示セルの形状・接続が既に失われている場合には、設定から
推測して復元しない。その盤面に残っている要素を保持する。過去に失われた要素・参照や、
旧アプリで既に別の場所へ割り当てられたIDを、この変更から復元することはできない。

## 対象範囲

この保証は除外、個別解除、一括解除、およびそれらの履歴・保存に適用する。
リサイズ・プリセットの変更・結合・分割など、盤面を再生成する別の編集は
[移行一覧](board-id-migration.md)の残課題。除外後にそれらを行う経路も今後の修正対象となる。
