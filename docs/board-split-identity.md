# セル分割と入力先の同一性

現在のセルの境界頂点2点を結ぶ線で分割する。セルIDや頂点IDは解析せず、
実グラフから頂点と境界を取得する。隣り合う頂点、境界外を通る線、別の境界頂点を
通る線は分割として受け付けない。凹形状では生成するセルの内側に数字の位置を置く。

元セルは消滅し、二つの子セルと分割辺に新しいIDを発行する。
既存の境界頂点・辺は同じIDと位置を保つ。元セルの数字・塗りを二つの子へ複製せず除去し、
生き残る境界の頂点注記・線と無関係なセルの注記は維持する。Undoでは全注記と試行状態を復元する。

「セルを復元」は元セルのIDと境界を戻し、子セルと分割辺の注記を除去する。
分割時に消えた元セルの注記を復活させる操作ではない。全状態の復元にはUndoを使う。
結合・分割を重ねた場合は、取り消した操作の出力に依存する後続操作も解除する。
別のセルに対する独立した編集は残す。

## 保存・表示変形・行列変更

ネイティブ形式1.5.0で、一つの元グラフ `editBase` と順序付きの `editOperations` を保存する。
分割操作は元セル、両端の頂点、新しい辺、二つの子セルのIDを明示する。
結合と分割を交互に行っても元グラフを入れ子にしない。
読込時は記録した操作を再適用し、境界・参照・存続要素の位置が保存グラフと一致するか検証する。
未知の由来を推測して既存IDへ付け替えない。

セルサイズ・余白・表示プリセット・除外との組合せも元グラフと操作のIDを保持する。
正方・六角格子の行列変更では元格子を編集して操作を再適用する。
削除した領域のセルとその子だけを除去する。
分割端点がなくなり、新しい境界との交点を作る必要がある縮小は未対応である。
その場合は盤面を変更せず、画面のApplyを無効にして理由を表示する。
低水準の `resizeTopology` も不対応をエラーで返す。

既知の旧結合ファイルからの追加分割は、既存の長い辺・斜めの辺も保持する。
[既知の旧分割ファイル](legacy-split-identity.md)は、辺途中を端点とする分割と旧結合との組合せも、保存済みのID・形状を保持して移行する。
除外・彫刻を伴う旧分割、未知の独自形状や他の格子の行列変更は残る。
不対応の拒否は移行完了とはみなさず、PR #126はDraftを維持する。

## 選択・数字入力

選択状態は `cellId` を必須とし、行列番号は任意の移動用メタデータとする。
行列指定で選択する既存APIも現在の盤面で一つのセルへ解決してから保存する。
該当なし・複数該当は未選択となり、IDの接頭辞や配列順で補わない。
通常のクリック・タップ、キーボード、数字パネル、候補・色・矢印設定、カーソル描画は
選択IDを解決する。未解決時に `cell-0-0` 等へ流すフォールバックを置かない。

行列番号がないセルの矢印移動は、実際の隣接セルの中心位置から方向・距離を比較する。
同率の候補がある場合や移動先がない場合は選択を動かさない。
行列を持つセルの移動は既存の行列範囲を使う。
[方向フリック入力](directional-input-identity.md)も実際のセルIDを保持し、マウス・タッチで行列のないセルを扱う。
ローマ字の遅延確定は、選択対象の削除・選択変更・盤面切替・レイヤー変更後に適用しない。

実ストアの分割・混合編集・保存・履歴テストと、実コンポーネントのキーボード／数字パネルの
入力テストで参照先を検証する。文字列の採番順ではなく、入力fixtureや操作結果のIDと比較する。
